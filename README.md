
# Patient Registration App

This is a full-stack patient registration app built using **Next.js** and **TypeScript**. Follow the steps below to get the app running on your local machine.

---

## ✅ Prerequisites

### 1. Check if Node.js is Installed

Open your terminal or command prompt and run:

```bash
node -v
```

If Node.js is not installed, download and install it from the official website:

🔗 [https://nodejs.org/en/download](https://nodejs.org/en/download)

After installation, run the command again to confirm:

```bash
node -v
```

You should see the installed version printed (e.g., `v20.10.0`).

---

## 🚀 Getting Started

### Step-by-Step Instructions (for **macOS**, **Windows**, and **Linux**)

---

### 🪟 Windows Users

1. **Open Command Prompt** (Search `cmd` in Start menu).
2. Run:
   ```bash
   git clone https://github.com/bhaveshranjan/Patient-Registration-APP.git
   ```
3. Open the folder in your code editor (e.g., VS Code).
4. Navigate to the project directory:
   ```bash
   cd Patient-Registration-APP/medblocks-task
   ```
5. Install dependencies:
   ```bash
   npm install
   ```
6. Start the development server:
   ```bash
   npm run dev
   ```
7. Open the printed `http://localhost:PORT` URL from terminal in your browser.

---

### 🍎 macOS Users

1. **Open Terminal** (⌘ + Space → type "Terminal" → Enter).
2. Run:
   ```bash
   git clone https://github.com/bhaveshranjan/Patient-Registration-APP.git
   ```
3. Open the folder in VS Code or your preferred editor.
4. Move into the project subdirectory:
   ```bash
   cd Patient-Registration-APP/medblocks-task
   ```
5. Install packages:
   ```bash
   npm install
   ```
6. Run the development server:
   ```bash
   npm run dev
   ```
7. Copy and open the URL (e.g., `http://localhost:3000`) shown in the terminal in your browser.

---

### 🐧 Linux Users

1. Open your terminal.
2. Run:
   ```bash
   git clone https://github.com/bhaveshranjan/Patient-Registration-APP.git
   ```
3. Open the project in your editor.
4. Navigate to the `medblocks-task` folder:
   ```bash
   cd Patient-Registration-APP/medblocks-task
   ```
5. Install the dependencies:
   ```bash
   npm install
   ```
6. Launch the app locally:
   ```bash
   npm run dev
   ```
7. Visit the local URL shown in your terminal in any browser.
